# 彰基糖友島 3D 島嶼網站（文獻知識島）建置計畫

本專案依據「造島工坊 IsleForge」規格與《2026臺灣糖尿病流行病學年鑑》教材，打造兼具溫暖手繪插畫風格與嚴謹實證醫學的 **3D 文獻知識島嶼網站**。訪客可在沉浸式 3D 群島間流暢探索、點閱文獻城市建築、學習衛教與臨床照護知識，並支援全年齡層無障礙操作與全功能離線運作。

---

## 決定事項與確認規格 (Confirmed Decisions)

> [!NOTE] 依據前次盤點與您的回覆，各項規劃確認如下：
> 1. **教材分配**：以年鑑第 1~3 章（流行病學、併發症與醫療利用、照護品質）建構「糖尿病知識島」；第 4~7 章（藥物治療、急症處置、肺炎與疫苗、成人健檢指標）建構「醫師人員島」；未經年鑑明載之補充文字均清楚標註「示意」。
> 2. **文獻建築設計**：文獻知識島的核心特色「一文獻一房子」，屋頂顏色代表文獻類型（實證研究／指引／回顧）、窗戶數代表研究作者群，每棟建築均提供 **APA 第 7 版引用一鍵複製**、DOI 外部連結、開放筆記與撤回檢驗標示。
> 3. **「醫師人員島」定位**：定位為「臨床醫療與照護專業站」，兼顧一般糖友（認識就醫檢查與共照網）與醫護專業（指引、用藥與指標），消除醫病資訊落差。
> 4. **吉祥物與小嚮導**：設定為「彰基糖糖衛教師（護理師）」，以溫暖親切的醫療手繪造型，引導遊客參觀並提供前端智能問答解惑。

## 二、使用者體驗與視覺設計 (UX & Visual Design)

1. **三組底色與主題切換**：
   - 預設「**薄荷**」`#e7f5f0`（清新自然，醫療綠底蘊）。
   - 「**米紙**」`#f8f4ea`（溫暖典雅，閱讀舒適）。
   - 「**墨色**」`#1e2426`（夜間護眼，海面與島嶼星光輝映）。
   - 主色 `#2a8a74`、強調色 `#e46a5e`，字體選用 Google Fonts `Huninn`（粉圓體）與 `Noto Sans TC`。
2. **3D 群島空間構成**：
   - 中央島（彰基糖友島）最大，兩側透過木橋與海面白帆航道連結島 1 與島 2。
   - 低多邊形（Low-Poly）手繪插畫質感，多層次島體、微波流動海面、散步小人物、燈塔發光、風車緩慢旋轉。
   - 支援 360° 拖曳旋轉、滾輪與雙指平滑縮放、點選島嶼平滑鏡頭巡弋（Damping 緩動飛行）。
   - **資訊分層**：3D 場景中僅浮動呈現島嶼標籤與關鍵狀態，點擊後展開抽屜面板（桌機右側滑出、手機底部抽屜），絕不遮擋 3D 主體。
3. **無障礙與 RWD 支援**：
   - 支援鍵盤 Tab / Enter / Esc 導覽，觸控按鈕 >= 44px。
   - 內建「**地點清單（純文字模式）**」，在不啟用 WebGL 或任何低階裝置下均能完整閱讀與操作所有文獻內容。
   - 支援「**減少動態**（Reduced Motion）」開關，停止旋轉與水波運動，保護暈眩體質訪客。

## 三、十五項完整功能與島型玩法 (Feature Specifications)

1. **搜尋功能**：支援島嶼、文獻標題、作者、關鍵字快速過濾。
2. **地點清單**：抽屜或獨立視窗呈現全站目錄，可依分類篩選，是 3D 之外的完整平等入口。
3. **探索進度**：以 LocalStorage 自動記錄造訪島嶼、已讀文獻與測驗狀態。
4. **減少動態**：一鍵暫停鏡頭自轉、水波波動與人物走動。
5. **小嚮導問答**：「彰基糖糖衛教師」純前端關鍵字比對年鑑醫學與衛教知識，附上出處島嶼連結。
6. **背景音樂**：採用 Web Audio API 純程式合成輕柔大自然海島旋律（鳥鳴、微風與手碟暖調和弦），由使用者手動啟動／靜音。
7. **小測驗系統**：中央島與兩座島各設 3 題糖尿病實證測驗，即時回饋解析。
8. **收集圖鑑**：包含 6 張主題成就卡片（如：流行病學探險家、控糖達人、心腎守護者），達成條件即時解鎖。
9. **完成證書**：全站探索完畢並通過測驗後，動態產生「彰基糖友島健康榮譽證書」，支援 PNG 下載或列印。
10. **晝夜光線切換**：白天晨光、金黃夕陽、沉靜星夜三段光照與陰影變化。
11. **每日鑰匙**：每日發放 3 把海島鑰匙，可用於開啟島上的「健康知識寶箱」。
12. **即時時鐘**：介面右上角顯示目前時間與日光天色狀態。
13. **分享卡片**：Canvas 動態合成專屬成就卡片與分享連結。
14. **小人物散步**：低多邊形小人偶沿著環島路徑慢速漫步，為島嶼注入生機與日常感。
15. **接關碼**：一鍵將探索進度轉化為 base64 加密字串，便於在跨裝置（手機與電腦）間無縫接續進度。

- **專案結構**：靜態標準架構，位於 `site/` 目錄下：
  - `site/index.html`：頁面入口與語意化結構
  - `site/styles.css`：Tailwind 核心變數、自適應抽屜與手繪插畫風組件
  - `site/js/app.js`：狀態管理、音效、測驗、證書與 UI 邏輯
  - `site/js/scene.js`：Three.js 3D 群島、建築模型、晝夜光影與動畫
  - `site/data/content.json`：整合《2026臺灣糖尿病年鑑》所有文獻、題目、島嶼資料，方便日後擴充維護
  - `site/materials/`：存放提供下載之 83.pdf
